# stepwise

Ejecuta comandos de shell desde ficheros de pasos, recordando por dónde va y permitiendo
**reanudar** desde el último fallo o desde cualquier punto con un menú interactivo.

> 🚧 En desarrollo: reescritura en Rust de [pyBashResume](https://github.com/Comunitea/pyBashResume).
